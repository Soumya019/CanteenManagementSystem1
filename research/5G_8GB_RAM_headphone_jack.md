## How this list was built

The request named 91mobiles as the source. 91mobiles is behind a Cloudflare
challenge that blocks automated access from this environment (HTTP 403 on every
endpoint, including `robots.txt`), so the list was built from **GSMArena** instead,
which exposes the same three attributes as structured spec fields.

Method:

1. Indexed every device in the GSMArena catalogue — **13,831 devices** across 126 brands.
2. Pre-filtered to phones announced 2019 or later, excluding tablets, whose maximum
   advertised RAM is at least 8 GB → **2,299 candidates**.
3. Fetched each candidate's spec page and parsed three fields verbatim:
   `Network → Technology` / `5G bands`, `Memory → Internal`, and `Sound → 3.5mm jack`.
   All 2,299 pages were retrieved successfully (0 fetch errors).
4. Kept devices where 5G is present **and** the `Internal` field lists an `8GB RAM`
   configuration **and** `3.5mm jack` is `Yes`.

A phone is included only if a single configuration meets the RAM criterion — a model
offered in 6 GB and 12 GB but not 8 GB is excluded even though 8 GB falls in its range.

  (for example "Redmi Note 14 5G" and "Redmi Note 14 5G (India)"). Where the memory or
  audio specs differ between variants, each qualifying variant appears on its own row.

  on that column for currently sold devices only.
